> **中文说明**：创建项目必须填写名称；整个项目仍保存在现有会话目录，重启后可以打开。

## Current-category filter

In 当前类别, the checkbox that keeps only samples with no subclass sits with the sample browser, above the recommend-category list.

> **中文说明**：“只看没有子类的样本”移到当前类别样本区上方、推荐类别列表之前。

## Save and load

Creating a project requires a name. An empty name, a name already used by another project, `|`, and a path separator (`/` or `\`) are rejected. The directory name stays an id. The name is stored with the session.

The project is the session the server already writes under its session directory (`web_sessions` by default). That directory holds the category graph, the mapper, classification and ranking weights, and the rest of the session needed to continue. A control lists those projects and loads the one you choose. Nothing is stored in a database.

> **中文说明**：名称不能为空、不能重复，也不能包含 `|` 或路径分隔符；打开项目只是重新载入已有会话目录。
