# Three-column board and certainty recommenders

> **中文说明**：标注页改成三栏工作板，推荐按当前层选中的类别集合计算，最明确和最不明确用 kNN 概率排序。

## Layout

The page is the board skin only (`data-layout="board"`). The left column is the recommendation images, with the recommend-category well under them. The center is the category graph. The right column is the classification / ranking well. The bottom strip is the score bins. Real thumbnails come from the session image route. There is no style switcher.

> **中文说明**：左栏是推荐图和推荐类别槽，中间是类别图，右栏是分类排序槽，底边是分数箱。

## Freeze and wells

Unfrozen, dragging a category card moves it and the edges follow. Frozen, the cards stay put, and a drag from anywhere on a card can drop that category into either well. Both wells use the same tag: one color, one row with the name and the sample count, and × to remove it. Each well has 选中全部 and 移除全部. 选中全部 fills the well with every category at the current graph level. Removing a tag drops that category from the recommend set or the task draft. Positions, freeze, edge mode, shot size, and well membership are stored on the session.

> **中文说明**：解冻时拖卡片改位置；冻结时把卡片拖进槽，槽里的标签可以单个移除或全部清空。

## Scoped recommend

Every recommender uses the selected recommend-category set. An empty set means every category at the current graph level. At the root, the pool is unlabeled samples and the classes are those root categories. Inside a category, the pool is only samples already assigned to that category with no subclass, and the classes are that category’s children. Samples from outside the category are not mixed in.

> **中文说明**：推荐只在当前层选中的类别里进行；槽为空就用这一层的全部类别，类内不再混入类外样本。

## Certainty

The one-class specified recommender is gone. 最明确 (`certain`) and 最不明确 (`uncertain`) rank the same pool with cosine kNN probabilities, k=15, on the mapped features when a mapper exists. 最明确 sorts by the highest max class probability, then the lower catalog index. 最不明确 sorts by the highest normalized entropy (`-sum(p log p) / log(n_classes)`), then a lower max class probability, then the lower catalog index. Random, diversity, and unknown stay, on that same pool. A recommend may refresh `pool_predictions`, but the ranking uses these probabilities rather than the stored hard label.

> **中文说明**：最明确看最大类概率，最不明确先看归一化熵，熵相同再偏向更低的最大类概率。

## Images and magnifier

小图 shows every image of the current page at once. 大图 shows one image and, after a successful drop, advances to the next unplaced image. A round that does not fit is paginated. Thumbnails use `object-fit: contain` inside a card that does not scroll. The magnifier is off by default. The toolbar button toggles it, and `M` toggles it when focus is not in a text field. Hover magnifies only while it is on. Score-bin images keep a 128px minimum height.

> **中文说明**：放大镜默认关闭，按钮或 M 键打开后，悬停才放大。

## Labels and strokes

Import reads `index, label_1, label_2, ...`, builds one class per primary label, then subclasses from the next column, and trains. Export writes each placed sample with ancestors filled out to its deepest label. The old one-column import still accepts an index column and a label column. 分离强度 sets edge width from that sibling edge’s separation strength, and the node outline from the mean separation strength of that node’s child edges (the default outline when it has fewer than two children). 映射距离 sets edge width from the mean mapped distance between the two nodes’ samples, and the node outline from the mean within-node mapped distance. A larger value draws a thicker stroke. Distances stay empty until the mapper has been trained.

> **中文说明**：CSV 用 index 和逐级 label 列导入导出；线宽可以在分离强度和映射距离之间切换。
