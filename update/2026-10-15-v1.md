# v1 category graph and feature map

> **中文说明**：第一版已在新的本地仓库实现，旧项目没有改动。

## What landed

The accepted discussion defaults are now code on branch `v1`.

- A cumulative exclusive category graph with nested categories and sibling relation strengths.
- One continued feature map. Manual reset replaces it. There is no automatic bake-off.
- Recommenders: random, diversity, unknown-category, specified-category kNN, and the algorithmic default.
- A Flask workbench: recommended images, the graph, and task classes for classification and ranking.
- A scripted four-way test plus a pairwise ranking check. It refuses the locked expert holdout.
- 33 pytest cases in conda `base`. A one-round smoke on the real FAMA features and development labels completed and wrote a report. That round contained no mergers, so the recommended-sample metrics were empty rather than forced.

## Not in this version

Non-exclusive graphs, mapper generations, pseudo-labels, guide-figure export, partial-graph edits, catalog-parameter labels, cross-dataset alignment, named relation types, and a separate model per subcategory.
